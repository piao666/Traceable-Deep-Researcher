# Contributing

Use [the project repository](https://github.com/piao666/Traceable-Deep-Researcher)
for issues and pull requests. Contact Piao666 at dahaipiao9@gmail.com.
Install with `pip install -e ".[test]"` and run offline tests with `TDR_BLOCK_NETWORK=1`.
Frontend edits should pass type checking and a production build.
Preserve source/license notices and keep credentials and generated data out of Git.
